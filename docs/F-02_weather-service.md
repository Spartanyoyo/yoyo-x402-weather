# F-02：Yoyo x402 天气服务 API

文档版本：0.1.1，2026-10-22。使用本服务前先阅读本文件。

本服务是 C。用户 A 可以自然语言提出查询需求，Codex B 根据本文组织请求。本接口由我们部署；它在官方 x402 组件外接入真实天气来源 D（MET Norway）。

## 服务入口

基地址：`{{BASE_URL}}`。

- `GET /health`：免费，查看网络、收款地址和价格。
- `GET /F-02.md` 或 `/llms.txt`：免费读取本说明。
- `GET /weather?latitude=...&longitude=...`：按次收费的天气查询。

## 从自然语言准备参数

| 参数 | 类型和范围 | 必填 |
|---|---|---|
| latitude | 十进制度数，-90 到 90，最多四位小数 | 是 |
| longitude | 十进制度数，-180 到 180，最多四位小数 | 是 |

本接口不接受城市名。收到城市名时，Codex 应通过可用的地理查询来源核实城市代表坐标，记录来源，再调用本服务。如果无法确定地点或有同名地点，先询问用户，不猜测位置。用户也可以直接提供坐标。

每个坐标参数只能出现一次，必须为十进制数字；不接受十六进制、二进制和科学计数法。服务将有效坐标四舍五入至四位小数。天气接口仅接受 GET，其他方法返回 405，且不执行天气查询或结算。

本阶段上海演示使用坐标 `31.2304, 121.4737`，代表上海市中心附近的演示位置，不表示用户的实际位置。查询其他地点须重新确认其坐标。

示例：用户说“查询上海现在的天气”，Codex 阅读本文，确认上海演示位置后请求：

```text
GET {{BASE_URL}}/weather?latitude=31.2304&longitude=121.4737
```

## 付款要求

- 仅 Base Sepolia 测试网，网络标识 `eip155:84532`。
- 仅测试 USDC，合约 `0x036CbD53842c5426634e7929541eC2318f3dCF7e`。
- 单次 0.001 测试 USDC，即该合约的 1000 个最小单位。
- 卖方收款地址：`{{SELLER_ADDRESS}}`。
- x402 V2，exact 支付方式，公共 facilitator：`https://x402.org/facilitator`。

先不带付款凭证请求，服务返回 402 和付款要求。买方使用官方客户端 SDK 解析要求并签名重试。核对网络、代币、收款地址和单次金额；不得使用主网或其他资产。只对配置好的这个服务地址发出本次授权的请求。

签名不等于扣款成功；成功结果须取得支付回执和链上交易证据。单次调用结束后不要自动再买一次。如付款状态不明，先查回执和链上记录。不得把手工转账与另一次免费天气请求拼成交易。

本机买方工具只接受当前服务 URL 的报价，授权有效期最长 300 秒，一次购买最多创建一个签名并提交一次付费请求。工具记录授权的公开字段（编号、金额和有效期），不记录私钥或可用于重放的完整签名。

## 成功结果

返回 JSON，包含 `requestId` 和 `weather`。天气字段包括 `location`、`dataType`、`provider`、`attribution`、`source`、`updatedAt`、`forecastTime`、`retrievedAt`、带单位的 `temperature`、`relativeHumidity`、`windSpeed` 及可能为空的 `summary`。

数据是 MET Norway 天气模型中距离当前时间最近的一项，非气象站实况观测。回答用户时注明查询位置、温度及单位、预报时间、数据来源；不要把预报说成实时观测。保留支付响应头，并与双方余额和链上转账对账。

服务校验温度、湿度、风速、源单位及时间；所选预报与请求时刻相差不超过 90 分钟，模型更新时间不超过 24 小时。字段无效、数据过期或上游失败时返回 502，不结算该次 exact 支付，也不缓存无效数据。正常响应必须同时具备有效天气、与正文一致的 `X-Request-Id`、支付回执及链上收付款证据，才能算完成购买。

## 错误

- 400：参数缺失、非数字或超出范围；在付款前修正。
- 402：需要付款或凭证无效；使用官方 x402 客户端处理。
- 405：请求方法不受支持；改用 GET。
- 502：上游天气请求失败；先查有无结算，不能盲目重试付款。
- 500 或 503：服务或结算组件不可用；保留错误并查明原因。

## 本机买方工具

在项目目录运行 `npm run probe -- <服务基地址>`，记录免费文档、健康检查与首次 402；运行 `npm run buy -- --base-url <服务基地址> --latitude 31.2304 --longitude 121.4737 --intent "查询上海现在的天气"` 执行一次购买。买方凭据仅从本机 `.env.local` 读取，不上传到云端。

`verified` 表示支付与天气交付均核验通过；`paid_delivery_failed` 表示已确认付款但天气交付失败，不能直接再次购买。`settled_audit_pending` 与 `outcome_unknown_check_chain_before_retry` 均须先只读查账。历史天气按原响应时间核验，不要求旧记录中的天气在今天仍然新鲜。

Cloudflare 临时预览地址需要在官方给出的期限内认领；如果尚未认领，不能把它描述为长期稳定部署。
